## Bottom line

The post is not one reusable product. It is a **composition** of five layers:

1. expensive/frontier inference supplied through subscriptions;
2. durable, repository-adjacent knowledge;
3. high-signal written rules and plans;
4. deterministic application state plus browser verification;
5. specialized agents that call small, custody-aware tools.

The strongest transferable ideas are **durable evidence, deterministic verification, bounded capability contracts, and fleet supervision**. The least transferable are the author's exact subscription scale, stack, personal products, and claim that continual learning is "solved".

## Evidence rules used in this pack

- **Verified** = live primary project/doc page or official documentation was fetched.
- **Author claim** = stated by Hraness but not independently established by the source set.
- **Unresolved** = named in the post/reply but no reliable public target was recovered.
- This pack does **not** treat a visible project page as proof of reliability, adoption, security, or business success.
