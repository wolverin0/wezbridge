# T-0598 Fase B-2 — DaemonSentinel → findings contract + schtask docs

Scope: scripts/daemon-heartbeat-sentinel.cjs emits ONE automation-router
finding per daemon outage past a consecutive-tick threshold (reusing the
existing episode/dedupe state), plus docs for the live
Wezbridge-AutomationRouter scheduled task and versioning
run-automation-router.cmd. Tier T3, branch
feat/t0598-faseB2-sentinel-finding from origin/main (5fba82d, includes #57
router + #58 sentinel-over-Orca).

## Plan

1. `evaluateFinding()` — new pure function, own state file
   (`daemon-sentinel-finding-state.json`), separate from the existing
   poke/episode STATE_FILE so finding-emission never perturbs poke/deadman
   behavior. Outage identified via evaluate()'s own
   `decision.newState.episodeStartedAt` (dedupe key). Threshold N=3
   consecutive outage-verdict ticks (down/wedged/http-unresponsive), ~15 min
   at the 5-min cadence — mirrors `HTTP_FAIL_STREAK_ALERT`.
2. `emitDaemonFinding()` — calls `bin/emit-finding.cjs`'s exported `main()`
   in-process (no subprocess), fingerprint `daemon-outage-<episodeStartedAt>`,
   actionable:true/severity:high for the outage finding, actionable:false/
   severity:low for the optional recovered finding.
3. Wire into `main()`: after the existing STATE_FILE write, read/evaluate/
   write FINDING_STATE_FILE in its own try/catch.
4. Tests: pure evaluateFinding unit tests (below/at/above threshold, dedupe
   across ticks, new outage after recovery, mutation-sensitive boundary at
   threshold-1 vs threshold) + one subprocess integration test reusing a temp
   WEZBRIDGE_INTEL_DIR across multiple sentinel runs to confirm the real
   finding file lands via bin/emit-finding.cjs.
5. Docs: docs/operations.md gets the Wezbridge-AutomationRouter schtask
   entry (cadence, launcher, cmdline, cwd+command, logs, undo, T-0600 gap
   note on sender identity).
6. Version `wezbridge/scripts/run-automation-router.cmd` if it's the file the
   scheduled task's .cmdline actually runs and is currently untracked.

## Acceptance criteria

- B2-1: sentinel emits exactly one finding per outage past threshold,
  red→green + mutation.
- B2-2: existing poke/deadman sentinel tests stay green (unchanged).
- B2-3: docs document cadence, cwd, command, logs, undo + gap note.
- B2-4: run-automation-router.cmd versioned, md5-identical to the file the
  live task runs.
