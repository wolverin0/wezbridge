One task's journey (the arrows version)

⏰ 08:00 sweeper runs› flags.json: whatsappbot: health-run› orchestrator session (or /intel-refresh) reads dashboard› ledger: create T-0007 state=ready + lease=whatsappbot-pane› a2a_send task packet: goal + acceptance criteria + scope + forbidden› whatsappbot pane runs /project-health --apply (its own subagents/Workflow inside)› returns envelope v2: criteria ✅/❌ + evidence + files_changed + next_action› orchestrator validates envelope (evidence present? criteria evaluated?) + acks immediately› ledger: T-0007 → done · event appended · dashboard regenerated› edge rule fires: on-done(T-0007) → dispatch review task to codex reviewer pane› reviewer (≠ builder) verdicts adversarially› gated action needed (commit/deploy)? → Telegram → you decide› same correction seen twice this month? → knowledge compiler → guard/test/skill
And when things die (the whole point):
orchestrator session depleted/killed›any fresh session reads _intel/›orchestrating again in ~30s — no handoff heroics
worker pane dies mid-task›lease expires›task back to ready, re-dispatched — work isn't lost, it's re-runnable
WezTerm crashes›snapshot restore (LEADER+R / npm run restore-session)›panes resume, ledger never noticed
PC reboots›schtasks re-arms the sweeper next 08:00›plane self-heals
